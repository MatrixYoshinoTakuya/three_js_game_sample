# ASHEN SKYLINE — 灰の摩天楼 / 設計メモ

[threejs-game-skills](https://github.com/majidmanzarpour/threejs-game-skills) の `threejs-game-director` の手順（設計ブリーフ → コアループ契約 → レベル計画 → 実装 → 証跡）に沿って作成。

## 設計ブリーフ

| 項目 | 内容 |
| --- | --- |
| プレイヤーの約束 | 灰に沈んだ摩天楼を武装車両で走り抜け、最後の中継塔を守り抜く |
| 狙う感情 | 孤独な疾走感 → 到達の高揚 → 包囲される緊張 |
| 主動詞 | 走る（加速・操舵・ドリフト） |
| 副動詞 | 撃つ（屋根砲塔の自動照準）、ブースト、体当たり |
| 5〜30秒ごとの反復 | 残骸を避けて交差点を曲がる／敵に砲塔を向けて撃つ／砲身の熱を冷ます |
| 1〜5分での変化 | 自由走行 → 斥候の襲撃 → 中継塔イベント → WAVE 1 → WAVE 2 → ボス |
| 失敗と再開 | 装甲 0 で大破。バトル中はウェーブ先頭のチェックポイントから即リトライ |
| 報酬とリスク | 高速ほど早く着くが衝突ダメージが増える。体当たりは強いが自分も削れる |
| 上手いプレイヤー | ドリフトで角を抜け、砲塔の旋回範囲に敵を置いたまま周回し、着弾円を避ける |
| 次の判断の伝達 | 光柱（中継塔）、コンパス、ミニマップ、目標パネル、無線、着弾円 |
| 対象外 | 徒歩、ミッション複数化、セーブ、車両カスタマイズ |

## コアループ契約

> プレイヤーは **走行と砲撃** で **中継塔の到達と防衛** を達成する。**錆牙団の追撃と迫撃砲** がリスクを生み、成功すると **次のウェーブと応急修理**、失敗すると **チェックポイントからのやり直し** になる。

| 条項 | コード上の裏付け |
| --- | --- |
| 動詞が実入力に接続 | `src/core/InputController.ts`（キーボード／マウス）、`src/ui/TouchControls.ts`（タッチ） |
| 目標が見える | `src/world/CityBuilder.ts` の光柱、`src/ui/Hud.ts` のコンパス・ミニマップ |
| 最初の1分に圧力 | `Game.spawnScout()`：出発から約12秒後に斥候が背後から出現 |
| 報酬が状態を変える | `Game.updateBattle()`：ウェーブクリアで装甲 +45、次段階へ |
| 失敗が原因を教える | `Hud.flashDamage()` の方向表示、`damageBy` の内訳計測 |
| 再開が速い | `Game.retry()`：Enter 1回でウェーブ先頭へ |

## レベル計画

- 形式：10×10 ブロックの格子状都市（約 1.1 km 四方）。道路幅 26 m、歩道は乗り上げ可。
- 出発点：南西の大通り。中継塔までは直線距離で約 890 m。
- ランドマーク：隣のビルにもたれた倒壊タワー、崩落した高架道路、中継塔の光柱。
- 最初の判断：残骸とバリケードを避けるライン取り。最初の脅威：斥候（約12秒）。最初の報酬：斥候撃破と無線。
- 緩急：自由走行（静）→ 斥候（動）→ イベント演出（静）→ WAVE 1/2（動）→ 応急修理（静）→ ボス（最大）。
- 予告：敵の発砲前はアクセント灯が強く光る。迫撃砲は約1.5秒前に赤い着弾円。
- 使い回し部品：ビル（4種の外壁スタイル×段状・ツイン・板状・廃墟骨組み）、街灯、残骸3種、瓦礫3種、バリア、ドラム缶、看板。

## 技術メモ

- 物理：自作のアーケード車両モデル（自転車モデル操舵＋横グリップ上限）。静的物体は AABB の空間ハッシュ、車両は前後2円。Rapier は不採用（高さ方向の物理が不要なため）。固定サブステップ 2 回。
- 描画：HDR レンダーターゲット（MSAA 4x）→ 深度ベースの高さフォグ（空の色に連動）→ UnrealBloom → 最終パス（光条・色収差・速度線・ACES・グレイン）。
- 都市：ユニットボックスの `InstancedMesh`。外壁の窓・割れ・煤はローカル座標から計算するプロシージャルシェーダー。
- 乱数：ゲームプレイの乱数は全てシード付き `rng` 経由。
- 外部アセット生成（Tripo／Gemini／ElevenLabs）は不使用。モデル・テクスチャ・音は全てコード生成。
